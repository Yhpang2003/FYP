## How to Run Locally
1. Clone this repository to your local machine.
2. Import the database schema (`fyp.sql`) into your MySQL database server.
3. Ensure a database named `fyp` is created, with user `root` and no password (or update `db_connect()` parameters in code accordingly).
4. Start the PHP server:
   ```bash
